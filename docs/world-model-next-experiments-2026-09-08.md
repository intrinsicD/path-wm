# Authorized bottleneck experiments — 8 September 2026

User approved the revised order: PushT perception, Paddle memory/prediction, then reconstruction retention. These are bounded exploratory comparisons, not an overnight curriculum rerun. Original checkpoints and raw datasets remain immutable. Estimated total implementation/training/evaluation time: 2–4 hours, to be refined from measured progress.

## 1. PushT frozen-feature pose accessibility

Use the selected task-only A encoder, the strongest previous pose baseline. Compare its original head with newly fitted linear, nonlinear flattened (hidden width 64), and spatial heads. Spatial head uses the fine map plus upsampled coarse map, shared convolutions, and three probability heatmaps: pusher, object center, and an orientation landmark 40 world units from the center. Decode expected coordinates and normalized landmark displacement to six pose outputs. Supervise pose and landmark coordinates; no transformed examples in this first attribution test, since that would introduce a second intervention. No keypoint detection labels from held-out images.

Train each fresh head 2,000 updates, batch 128, AdamW 0.0003, weight decay 0.0001, clip 1, seed 6107; identical frame draws. Cache exact frozen FP32 features from all 20,493 training frames and original validation/test splits. Fixed 2,048 validation frames seed 6107; select minimum existing q=max(position MAE/8, angle MAE/10), then pose MSE, then earliest. Final and selected are both evaluated. Report original head on identical populations, full test and matched training diagnostics, per-configuration errors, circle norm and keypoint heatmaps. A relative improvement is q at least 10% below original on validation; absolute readiness remains q≤1. No PushT U/P training follows this diagnostic, even on a positive exploratory result. Head parameter counts differ, so capacity and spatial bias are not isolated from each other. Per-head wall limit 1,800 seconds.

## 2. Paddle memory accessibility and physical predictor objective

Freeze existing E/U/H/R and selected P5. Fit fresh linear and MLP (128→128→5) state readouts on existing full-history training memory, excluding t<2. Use all training episodes, normalized targets [64,64,6,6,64], seed 6107, 2,000 updates, batch 256, same optimizer and draws; select validation normalized MSE. Evaluate original and refitted readouts on all validation/test observations and short-history/collision slices. This is a probe, not replacing the deployed R. A velocity probe is eligible for a training loss only if BOTH validation velocity MAEs are ≤0.5 pixels/interval and neither exceeds original R. Otherwise explicitly defer velocity supervision and test position loss alone.

Continue identical copies of selected P5 for 2,000 updates, batch 16, horizon 5, seed 6107, fresh identical AdamW optimizers: latent-only control versus latent + physical objective. Physical position error is mean squared world-unit error divided by 2²; eligible velocity error is divided by 0.5². Average over coordinates/horizons; add physical term with coefficient 0.1, fixed in advance. Maintain gradient through frozen H/U and eligible readout; optimizer owns only P. Uniform identical training windows retain their natural collision distribution; report collision and no-collision errors separately instead of changing sampling simultaneously. Select both arms using the same validation five-step H position MAE (mean of coordinates), then latent loss; evaluate final as a secondary check. Per-arm wall limit 1,800 seconds.

Compare original P5 and both selected continuations on identical 1,024 test prediction windows and 100 ordinary plus 50 paired starts (25 pairs), learned controller only, original 200-step bound and 243-action-sequence planner. No comparison against historical case subsets without matching IDs. Report paired case/group bootstrap intervals conditional on models. Candidate objective is promising only if validation mean H error improves ≥10% over matched latent control without any coordinate worsening >5%; test and controller outcomes describe transfer and do not retune selection. Velocity eligibility failure is an informative gate, not authority to expand its fitting budget.

## 3. Decoder retention and domain conditioning

Freeze task-adapted B encoder and start both decoders from the same original task decoder. Compare unconditioned mixed-data decoding versus domain-conditioned decoding. Each update contains 64 COCO and 64 PushT training images, independently sampled but identical across arms; 2,000 updates, seed 6107, same optimizer. Conditioning is an additive learned RGB-logit bias per domain, initialized to zero so both decoders initially compute exactly the same function. This is a minimal domain-conditioning test, not a test of all possible conditional architectures or reconstruct/predict task tags.

Select minimum worst-domain MSE divided by the preserved domain-reference MSE (COCO original warmup, PushT adapted pair), on fixed 2,048 validation images per domain; tie-break average ratio then earliest. No test-based normalization or model selection: denominators are recomputed on validation references before training. Evaluate all test frames, original references, selected/final models, and fixed image panels. Conditioning is promising if validation worst ratio improves ≥10% over mixed unconditioned, with neither domain error worsening >5%; report failures honestly. Per-arm wall limit 1,800 seconds.
