  `constant` control supplies `.` through that route; `instruction` supplies the
  actual question. Identical new modules, initialization and parameter counts.
  No answer, choice list, case ID or sample ID is passed to request metadata.
  Task ID/actor/output metadata are constants across examples. No-request calls
  preserve the existing path. Default `none` remains supported without new modules.
- Two original joint-native sources7201/7202; four fresh fits. Existing core/text
  decoder plus new task modules train; encoders/nontext decoders remain frozen.
  Same768 updates,384 QA/384 original supervised replay, batch8, Adam0.001,
  clipping5 and replay-only source-output anchoring10 in both arms. New modules
  initialize without perturbing the training random stream. No weight sweep or
  final-checkpoint selection; old sources remain untouched.
- Training uses only the16 full-profile VID.order calibration clips, each with
  four requests: two ask first color, two ask both colors in temporal order.
  Thus64 training examples; byte CE including EOS. Targets use the same color
  vocabulary. One training request pair has equal UTF-8 length (`Erste Farbe?` /
  `Beide Farben`), so request length cannot uniquely determine output length.
- Test both familiar and two unseen wordings per format on all16 held-out target
  clips with three common paired draws. A novel request pair also has equal length
  (`Welche Farbe kam zuerst?` / `Welche Farben der Reihe?`). Keep answers, queries,
  EOS completion and exact/first-word outcomes inspectable. Max16 generated bytes;
  every target fits with EOS. Do not truncate strings into a passing answer.
- Six inference conditions: full; video omitted; last frame only; constant direct
  request with real observed question; generic observed question with real direct
  request; generic observed question with reversed-character direct request.
  All retain identical fixed metadata and paired random noise. These ablations
  localize routing/length dependence, not general natural-language understanding.
  Constant control still sees the real question through observations.
- Run the unchanged25-family quick task battery plus the larger VID.order choice
  task. Evaluation implementation changes require fresh original-source reference
  evaluations; verify their raw predictions match the historical references.
  Do not silently compare incompatible saved evaluation contracts.
- Adoption requires original VID.order choice/pair gates in both profiles/seeds;
  novel-wording exact free answers >=80% for each format AND both formats on each
  clip/wording, in every draw; treatment improves novel joint accuracy by>=10pp over
  constant control in both seeds. No-evidence and last-frame free exact <=60% per

- Budget: each fit/evaluation<=600s, peak PyTorch allocation<6GiB, formal artifacts
